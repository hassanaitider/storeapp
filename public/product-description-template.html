اطلب الآن عرض الصور
دليل سريع:
• الصور/GIF: أزل التعليق عن وسم <img> داخل كل .media-slot وضع المسار.
• الألوان: عدّل style="background: ..." واسم .swatch__name.
• الخطوط: .t-hero / .t-title / .t-section / .t-lead / .t-body / .t-caption.
• أحجام الكتابة كلها من متغيرات :root (--text-xs … --text-hero).
